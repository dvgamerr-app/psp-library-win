Know every PSP ISO
before you launch it.

PSP Library reads your game folder and shows each game's cover, title, catalog ID, region and firmware, so file names like cvn-tokd.hako stop being a mystery.

What you get

Everything is read from the game's own files, nothing is downloaded.

📚 Library list

Catalog ID, file name, region and firmware for every ISO in your folder, sortable.

🖼️ Cover and background

The game's icon and PIC1 background pulled from inside the ISO.

🔎 Game details

Title, version, firmware, parental level, disc type, size and created date.

🪟 Quick viewer

Open one .iso with PSP Library to see its details without scanning a folder.

📊 Collection summary

Total games, total size and an English / Japan / Other split.

🔒 ISOs stay untouched

Games are opened read-only. Metadata is cached in a PSPStore folder next to the app.

Get started in a minute

No installer. Needs Windows with .NET Framework 4.0 or newer.

  1. Download psp-library-v1.1-release-x64.zip (or x86) from the latest release.
  2. Extract it anywhere and run PSPlibrary.exe.
  3. Choose the folder that holds your PSP games and wait for the scan.
  4. Want just one game? Run:
    PSPlibrary.exe "C:\path\to\game.iso"
Heads up: the scan moves any .iso, .cso or .pbp sitting directly in your chosen folder into a sub-folder named after the file. Use a folder you are happy to have tidied, or back it up first. Details are read from .iso only for now.
